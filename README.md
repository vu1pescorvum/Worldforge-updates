# Worldforge · обновления приложения

Официальный канал распространения Windows x64-версии Worldforge.

## Установка

Откройте [последний стабильный выпуск](https://github.com/vu1pescorvum/Worldforge-updates/releases/latest), скачайте Worldforge-Setup и установите один раз. Следующие обновления приложение проверяет при запуске. Пользовательские проекты остаются в выбранных пользователем папках.

## Что здесь публикуется

- `vX.Y.Z`: Windows-установщик, blockmap и manifest для обновления оболочки.
- Предварительный выпуск `content`: подписанный Ed25519-пакет исполняемых ресурсов интерфейса. Обновления интерфейса не требуют повторной установки Electron.

Исходный репозиторий разработки приватный. Здесь нет личных проектов, учётных данных, секретных ключей и исходной Git-истории. Исполняемые клиентские ресурсы входят в распространяемое приложение и могут быть просмотрены пользователем.

При недоступности сети приложение использует последнюю рабочую версию. Пакеты интерфейса проверяются до применения; неподтверждённый запуск откатывается. Текущие бета-установщики пока не имеют Windows-сертификата издателя; Ed25519-подпись пакета содержимого не заменяет Authenticode.
