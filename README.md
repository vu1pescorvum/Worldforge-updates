# Worldforge — Windows-приложение

С версии 1.0.0 основная версия Worldforge работает на .NET 10, WPF/Blazor Hybrid и C# Runtime с нативным Yrs. Electron и Node.js в установщик не входят.

## Установка

Откройте [последний стабильный выпуск](https://github.com/vu1pescorvum/Worldforge-updates/releases/latest) и скачайте **Worldforge-Setup-1.0.0.exe**. Пакет предназначен для Windows x64, содержит .NET и автономный WebView2. Установка выполняется для текущего пользователя. Проекты остаются в выбранных вами папках; удаление приложения их не удаляет.

Сохраняются прежняя идентичность установки и основной профиль Electron. Недостающие проекты и ключи из .NET Preview импортируются однократно. Preview-профиль и отдельная Preview-установка сохраняются.

## Обновления

Приложение проверяет обновления в фоне. **Обновления → Скачать обновление → Установить и перезапустить**. Можно отменить загрузку и продолжать работать без сети. Перед установкой проверяются подпись Ed25519, размер и SHA-256; перед закрытием сохраняются изменения. Установщик проверяет новый пакет до замены и оставляет предыдущую установку в соседнем резервном каталоге.

Релизы `vX.Y.Z` содержат установщик, подписанный `worldforge-app.json`, `SHA256SUMS.txt` и `latest.yml` для перехода старых установок Electron. Канал `content` сохранён только для прежних версий; .NET не загружает отдельные JS/CSS-обновления.

Для совместной работы вся команда переходит на .NET (протокол 9). Совместной сети с Electron нет. Для старой оболочки доступен отдельный экспорт проектов в формат 5; приложение не понижает формат проекта при откате версии.

Исходный репозиторий приватный. Здесь публикуются только установщики, манифесты и документация распространения — без личных проектов, учётных данных, секретных ключей и исходной Git-истории. Сертификата Windows Authenticode пока нет; Ed25519-подпись обновления не заменяет подпись EXE для SmartScreen.
